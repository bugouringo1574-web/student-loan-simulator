# 学費ローン＆生活設計シミュレーター

学費ローンの年次別（3回分割借入）ごとの借入額・金利差、将来の想定年収から算出した手取り額、一人暮らしの生活費の内訳を考慮し、無理のない返済計画と生活の安心度を多角的に診断するWebアプリケーションです。

## 主な機能

1. **年次別（3回分割）借入＆金利設定**
   - 1年目、2年目、3年目の借入金額および金利（年利%）を個別に設定可能
   - 加重平均金利・借入総額の自動算出

2. **返済方法の柔軟なシミュレーション**
   - 返済期間（年数指定）からの月々返済額計算
   - 毎月の希望返済額指定からの完済年数計算

3. **繰上げ返済シミュレーション（期間短縮型）**
   - 指定した年数に繰上げ返済を行った場合の利息削減効果と短縮期間の試算
   - 通常返済 vs 繰上げ返済のビフォーアフター比較表

4. **税金・社会保険料を控除した推定手取り計算**
   - 額面年収から所得税・住民税・社会保険料（健康保険、厚生年金、雇用保険）を自動控除して手取り月収・年収を算出

5. **詳細な生活費・貯蓄設定＆生活安心度判定**
   - 家賃、光熱費、食費、通信費（スマホ・WiFi）、交際費などの内訳入力
   - 月々の収支バランス（スタックバー）と返済負担率（DTI）に基づく安心度バッジ・アドバイス表示

## 使用技術

- HTML5
- CSS3 (Vanilla CSS / レスポンシブ対応)
- JavaScript (Vanilla JS / ES6+)

## 使い方

1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をブラウザで開くだけですぐに動作します（ビルドやサーバー構築は不要です）。
