# 学費ローン＆生活設計シミュレーター

学費ローンの年次別（3回分割借入）ごとの借入額・金利差、将来の想定年収から算出した手取り額、一人暮らしの生活費の内訳を考慮し、無理のない返済計画と「繰上げ返済による利息・期間削減効果」を多角的に診断・可視化するWebアプリケーションです。

## 主な機能

1. **年次別（3回分割）借入＆金利設定**
   - 1年目、2年目、3年目の借入金額および金利（年利%）を個別に設定可能
   - 加重平均金利・借入総額の自動算出

2. **返済方法の柔軟なシミュレーション**
   - 返済期間（年数指定）からの月々返済額計算
   - 毎月の希望返済額指定からの完済年数計算

3. **高度な繰上げ返済シミュレーション（2大方式対応）**
   - 🚀 **期間短縮型**: 毎月の返済額を維持し、高金利ローンから優先元金充当して完済時期を大幅短縮＆利息を最大節約
   - 💰 **返済額軽減型**: 完済期間を維持し、繰上げ返済後の毎月の返済額を安くして生活のゆとり・自由資金を拡大
   - ビフォーアフター比較表＆削減メリット（利息削減額・短縮期間／月々軽減額）のリアルタイム表示

4. **残高推移のSVGビジュアルグラフ＆年次詳細スケジュール**
   - 通常返済 vs 繰上げ返済のローン残高推移を比較プロット
   - 繰上げ返済実行ポイントのハイライト表示
   - 年次ごとの年間支払額・利息・繰上げ額・年末残高テーブル（アコーディオン）

5. **税金・社会保険料を控除した推定手取り計算**
   - 額面年収から所得税・住民税・社会保険料（健康保険、厚生年金、雇用保険）を自動控除して手取り月収・年収を算出

6. **詳細な生活費・貯蓄設定＆生活安心度判定**
   - 家賃、光熱費、食費、通信費（スマホ・WiFi）、交際費などの内訳入力
   - 通常返済時／繰上げ返済後の収支バランス（スタックバー）と返済負担率（DTI）に基づく安心度バッジ・アドバイス表示

## 使用技術

- HTML5 (セマンティックタグ)
- CSS3 (Vanilla CSS / レスポンシブ対応 / フィンテック調モダンデザイン)
- JavaScript (Vanilla JS / ES6+) / SVGグラフィックス

## 使い方

1. `index.html` をブラウザで直接開くだけですぐに動作します（ビルドや外部サーバー不要）。
